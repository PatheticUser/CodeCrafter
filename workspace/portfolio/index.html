✦ Features

Built for the Terminal

Everything you need from an AI coding agent, designed for speed and control.

⚡

Cloud-Powered Inference

No need for a local GPU. CodeCrafter uses hosted cloud models for fast, intelligent responses with automatic fallback when a model is unavailable.

📁

Local File Operations

Reads, writes, edits, and deletes files in your project directory — all sandboxed with path traversal protection.

⚙️

Multi-Language Execution

Run Python, JavaScript, C++, HTML, and more directly from the CLI. Auto-detects language and installs missing dependencies.

🔄

Self-Correcting

Automatically detects runtime errors, installs missing packages, and retries — no manual intervention needed.

💬

Persistent Sessions

Full conversation history preserved across restarts. Save, load, and manage multiple sessions effortlessly.

🔒

Sandboxed Security

Path traversal protection, command blocklist, and workspace confinement keep your system safe from destructive operations.

⌨️ How It Works

Start in Seconds

One install, zero config. Run it in any project directory.

Install CodeCrafter

Clone the repo and install dependencies with a single command.

git clone && uv sync

Run It in Your Project

Navigate to any project and start the agent. It reads your workspace automatically.

cd my-project && uv run main.py

Describe What to Build

Just type what you need. CodeCrafter writes code, runs commands, and debugs errors — autonomously.

build a REST API with FastAPI
⌨️ Commands

Control from the CLI

All the commands you need, available right in the agent session.

Command Description
help Show available commands and usage
sessions List all saved sessions
session new Start a fresh session
session load <name> Resume a previous session
session delete <name> Delete a saved session
clear Clear current conversation history
exit / quit Save and exit the agent

🔒 Security

Safe by Default

CodeCrafter executes code on your local machine with multiple safety layers.

✓

Workspace Confinement

File operations are restricted to the working directory with path traversal protection.

✓

Command Blocklist

Destructive patterns (rm -rf /, mkfs, etc.) and sensitive paths are blocked by default.

✓

No Remote Execution

Everything runs locally on your machine. No code is sent to external servers for execution.

✓

You're in Control

Review what the agent writes and runs. All actions are displayed in real-time in the terminal.
